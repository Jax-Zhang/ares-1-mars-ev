# ARES-1 火星装甲电动车 · 整车研发与制造全流程平台

ARES-1 火星装甲电动车整车研发与制造全流程平台。它是一个由 AI 驱动的整车研发可视化平台：用 AI 生图和 Hi3D 生成 3D 模型，在一个网页里打通一辆火星装甲车从立项、造型、工程设计、仿真验证，到数字孪生产线装配和下线检测的全过程。

**在线演示：** https://jax-zhang.github.io/ares-1-mars-ev/

> 默认加载轻量模型（约 36 MB，本机 3 秒左右加载完），建议使用桌面版 Chrome / Edge。在网址后加 `?hq=1` 可加载 Hi3D 原始高精度模型（约 370 MB）。

## v3 更新（2026-11-11）

- G1 概念与造型支持左右舱门、前舱盖、后舱盖开合，新增双座内饰及灯组细节；轻量版与 `?hq=1` 高精度版均包含对应模型。
- 新增“体验模式”：在火星地形驾驶车辆，可使用方向键，也可主动开启摄像头，通过身体姿态模拟方向盘操作。
- 姿态识别所需的 MediaPipe 脚本、WASM 和模型随仓库提供；本地启动器支持对应文件类型。
- 当前更新保存在 `v3` 分支。上方在线演示链接的内容取决于 GitHub Pages 配置，不随本分支推送自动切换。

## 解决什么问题

- **研产供销服数据不通**：研发、制造、采购、销售、售后各用各的系统，变更靠人传。
- **研发周期长**：全新平台从立项到量产通常 3–4 年，实物验证慢，越晚发现问题代价越高。

## 做了什么（按 G0–G6 行业门径）

| 阀门 | 阶段 | 页面内容 |
|---|---|---|
| G0 | 立项定义 | 火星着陆场景，概念全息轮廓，环境与需求定义 |
| G1 | 概念与造型 | AI 四视角概念图 → Hi3D 生成的整车 3D 模型（轻量版 99 万面；`?hq=1` 为 496 万面原始模型） |
| G2 | 工程设计 | 13 个 Hi3D 零件的动态爆炸图、BOM 与系统归属 |
| G3 | 样车与验证 | 9 项设计验证：风阻、极寒、抗辐射、着陆冲击、爬坡、推进喷气等，附实时曲线；外星人彩蛋（变形机甲，拳打脚踢五连击） |
| G4 | 工装与产线 | U 形总装线布局，10 工位、物料流向 |
| G5 | 试生产与爬坡 | 数字孪生产线：逐工位流转，机械臂、人工、AGV 补给同步 |
| G6 | SOP 与下线 | 8 项 EOL 检测：外观光隧道、转毂、淋雨、涉水、快充、气密、高压、推进冷试 |

右上角“更换车型 / 上传模型”可上传新的 GLB 车型，复用整条流程。

## 本地运行

Windows：双击 `START.bat`（有 Node.js 就用 Node，否则用系统自带 PowerShell，无需安装任何东西），浏览器会自动打开 http://localhost:5173/ 。

其他系统：在 `site/` 目录运行任意静态服务器，例如 `python3 -m http.server 5173`。

## 技术栈

- 3D 资产：Hi3D（图生 3D，v3.0 高质量），概念图由 AI 生图生成
- 渲染：three.js 0.160（已内置在 `site/vendor/`，离线可用）
- 轻量模型：`site/lite/` 由 `tools/build-lite.mjs` 离线生成（gltf-transform 减面 + Pillow 缩贴图 + meshopt 压缩），原始模型保留在 `site/model` 等目录
- 单文件页面 `site/index.html`，无构建步骤

*验证、产线与检测数据为方案阶段的仿真示意值。*
